# Dataflow report reference archive

This directory contains locally available papers cited by
`dataflow-models-of-computation.tex`. Citation keys and bibliographic metadata come from
`dataflow-models-of-computation.bib`.

The coverage figures and downloaded/missing lists below are the audit snapshot from 2026-09-12.
Each PDF is named after its bibliography citation key. PDFs in the original audit passed `pdfinfo`
and `pdftotext`; the later additions listed below were checked for a PDF file signature.

project sites, and public preprint archives. Some entries are books, standards, software projects, or
